# Blueprints personnalisés Home Assistant

Stockez ici tous les blueprints créés sur-mesure pour factoriser des logiques domotiques récurrentes (usage automatisations YAML par pièce ou `shared/`).

## Convention
- Fichier dash-case en français (ex: `lumiere-sur-mouvement.yaml`)
- Documenter le blueprint en français au début du fichier
- Ajouter un exemple d’utilisation dans le README ou en commentaire dans le blueprint

## Exemples attendus
- `lumiere-sur-mouvement.yaml` : Pour l’allumage/extinction automatique d’une lumière sur détection de mouvement, généricisé.
- `tempo-edf-alert.yaml` : Pour les automatisations de notification ou d’action lors d’un changement de couleur Tempo EDF.
